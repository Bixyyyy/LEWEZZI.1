# LEWEZZI — Fashion Gateway Demo v9 + Account Pages

A responsive clothing discovery mall prototype with matching Log in and Sign up pages.

**Brand line:** LEWEZZI — A world of brands, one destination.

## Files
- `index.html` — LEWEZZI fashion mall homepage based on the v9 design, including circular brand gates, searchable clothing discovery, garment rows, and Log in / Sign up links.
- `login.html` — Front-end login form with validation, show/hide password, remember-me checkbox, and demo-only password reset feedback.
- `signup.html` — Front-end signup form with name/email/password validation, password confirmation, and show/hide password.

## Run
Extract this ZIP and open `index.html` in a browser. Keep all three HTML files in the same folder so the homepage and account links work together.

## Important demo limitation
These are UI prototypes only. They do not create accounts, authenticate users, store passwords, or send reset emails. Do not enter real credentials. Real account support requires a secure backend, password hashing, session management, email verification, rate limiting, and a password-reset flow.

The site images, brand icons, and web fonts use external sources, so an internet connection is needed for full visuals.
